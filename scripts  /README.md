## `create-ubuntu-template.sh`

Этот скрипт автоматизирует создание шаблона виртуальной машины Ubuntu 22.04 в Proxmox. Он скачивает официальный Cloud Image, импортирует его, расширяет диск, настраивает Cloud-Init (DHCP) и превращает ВМ в шаблон.

### Требования

Перед запуском убедись, что выполнены следующие условия:

- **Пользователь:** запуск только от `root` (скрипт использует `qm` без `sudo`).
- **Хранилище:** в кластере Proxmox существует хранилище с именем `local-lvm`.  
  Проверить: `pvesm status`
- **ID шаблона:** ID `9000` должен быть свободен.  
  Проверить: `qm list | grep 9000` (если пусто — всё ок).
- **Сеть:** на хосте настроен сетевой мост `vmbr0`, к которому будет подключена ВМ.
- **Доступ в интернет:** хосту нужен доступ к `cloud-images.ubuntu.com` для скачивания образа (~2 ГБ).

### Как запустить

#### Вариант 1: Безопасный (рекомендуется)

Скачивает скрипт во временный файл, проверяет права и запускает. Позволяет вручную убедиться, что скачался именно скрипт, а не HTML-страница.

```bash
curl -s https://raw.githubusercontent.com/Linuh-ru/homelab-infrastructure/main/scripts/create-ubuntu-template.sh \
  -o /tmp/create-template.sh && \
chmod +x /tmp/create-template.sh && \
/tmp/create-template.sh
```

#### Вариант 2: Быстрый (только если доверяешь источнику)
Однострочник для быстрого запуска:

```bash
wget -qO- https://raw.githubusercontent.com/Linuh-ru/homelab-infrastructure/main/scripts/create-ubuntu-template.sh | bash
```
⚠️ Важно: Не используй этот вариант в автоматизированных пайплайнах без дополнительной проверки целостности (например, SHA-сумм), так как любая ошибка сети приведёт к выполнению неполного или повреждённого кода.

#### После успешного завершения проверить, что шаблон создан:

```bash
qm list | grep 9000
```
Ожидаемый вывод:
```text
      9000 ubuntu-22.04-cloudinit stopped    2048              20.20 0         
```
Или через веб-интерфейс Proxmox: в списке виртуальных машин должна появиться запись с именем ubuntu-22.04-cloudinit и пометкой «Шаблон».
